# 09 — v0.1から実装への判断記録

> 2026-10-25の操作改善により一部の記述を更新。[現行の操作と変更理由](11_DIRECT_COMPOSITION.md)、[最新の比較・検証](12_DIRECT_VALIDATION.md)を優先する。以下は初回設計／実装時の記録として保持。

2026-10-25 JST。開始コミット `63d91e2`。指定されたREADMEと設計書01–07を読み、以下を具体化した。

| 判断 | 理由 | 影響・検証 |
|---|---|---|
| TypeScript + Vite、フレームワークなし | この規模ではDOMのヘッダー/パネルとCanvas2Dの1枚で実装できる。音符1個を動かすために画面全体を再生成しない | 外部の実行時UI依存なし。構文/型はtsc、描画と操作は実ブラウザー |
| Canvas2Dと音高別インデックス | 10,000音を測定してからGPU等の追加を判断する | 画面内の音だけ描画。全体図は小さいCanvas。入力/保存/音源のPromiseをパンの前提にしない |
| Pointer Eventsの状態機械 | ツール切替より触れた対象と移動量を用いる | touch 8px、mouse/pen 4px、長押し460/420msは暫定。実機による閾値調整は未確認 |
| 2本指を最優先 | 最初の指が音符を動かしていても操作空間を解放する | 未確定draftを破棄し、両指が離れるまで音符編集へ戻さない。正式データにドラッグ中の値を入れない |
| 短音符のハンドルを選択後に拡張 | 短い音の中央と右端を同じ数pxへ詰め込まない | 通常の短い音は中央ドラッグ、長押し後に外側ハンドル。数値編集も用意 |
| 詳細は側面/下部のパネル | 普段は1本のヘッダーと1本のフッターに絞る | 編集場所を覆う位置固定メニューを避ける。曲設定は×/外側/開くボタン/Escapeで閉じる。Canvasへの外側タップは閉鎖だけに消費 |
| tick=960 PPQとstable ID | 浮動小数の秒を編集データにしない | 1操作1revision、Undo/Redoでもrevisionは増加。複数音の音域外移動は一括拒否して音程関係を維持 |
| 保存専用WorkerとIndexedDB | IDB要求、検証、前回正常状態のコピーを入力経路から外す | 期待stampが異なるタブの上書きを拒否。保存完了ACK後だけ「保存済み」。失敗時も編集と外部書出しを残す |
| Web Audioのネイティブサンプル発音 | DSPをJavaScriptタイマーで1サンプルずつ計算する必要がない | 25ms毎に180ms先をオーディオクロックへ予約。表示は同じ時計の拍位置から得る。再生中編集は未発音予定だけ差替え |
| SF3全体でなくピアノだけ配布 | 提供ファイル86MBを起動必須にしない | 実ファイルINFO/ICMTのMIT許諾・権利表記を確認。Splendid Grand、MF/FFの20アンカーずつ40ステレオMP3、4,693,896bytes。ライセンス全文を同梱 |
| 元音源と異なる軽量サンプラー | 全SF3エミュレーションを作る前に実際にピアノ曲を作れる形にする | 2速度層・音高に応じた再生速度・強弱ゲイン/フィルター・200msリリース。元音源との厳密な音響同一性は主張しない |
| デコード済みPCMのLRUを48MiBに制限 | 全86MBのSoundFontをデコードしない | 発音中ノードが持つPCMとブラウザー全体のメモリはこの上限の外。総メモリの実機測定は未確認 |
| 音源変換を一時領域→原子的配置に変更 | 検査で空ファイルを確認した | 変換後にFFmpeg再デコード検査、byte数/SHA-256のビルド時照合。ブラウザーでも全サンプルをデコードする |
| 全資産を同じオリジンへ同梱 | オフライン作曲と音源取得を一致させる | 外部CDN/フォント/分析通信なし。Service Workerの全資産取得に成功した後だけオフライン準備完了 |
| 静的キャッシュのOrigin差を吸収 | CIのネット切断で、キャッシュ内のJS/CSSが `Vary: Origin` のため検索されないことを追跡記録で確認 | ビルド資産の明示リスト内に限り `ignoreVary` を用い、API等の他URLには適用しない。実際のネット切断・再読込試験で回帰確認 |
| 元案と別案を明示保存 | Undoと創作上の候補を混ぜない | フレーズ化時にA案。B以降は明示保存。選択して試聴/適用、適用もUndo可 |
| 公開先の設定を別扱い | リポジトリはPages未有効だった | GitHubのCI/Pagesワークフローを追加。PRは自動マージしない。試用ページはSitesへ同じソースから配布 |
