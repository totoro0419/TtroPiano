# 07 — 100課題への対応表 / Traceability

この一覧の100項目は、前段の検討で抽出した**既存DAW一般に対する設計上のリスク・論点**であり、特定アプリに欠陥が100件存在すると実証したものではない。各項目を個別の機能追加で解決せず、10の共通設計に統合する。

## 追加しないことで守ること

1. 100項目を100個のボタンや設定に変換しない。
2. 数多くの隠しジェスチャー、AIによる無断変更、使わない常設パネルを増やさない。
3. 緻密な音楽的推論や自動演奏指使い判定は、MVPの必須条件にしない。
4. 各設計の良し悪しは実機・初見操作テストで判断し、問題があれば設計自体を改める。
