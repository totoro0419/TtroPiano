## 確認した問題と修正

| 作曲中の意図 | 改善前 | 今回の動作 |
|---|---|---|
| 続けて音を置く | 選択中の空白タップは選択解除に消費 | 空白タップは常に1音追加。直前に置いた音を選択するため、そのまま修正・試聴できる |
| 動かした音をさらに直す | 移動後に選び直す場面がある | 移動・伸縮が終わった対象を選択。タップ削除は音符本体で引き続き有効 |
| 既存の1音を選ぶ | 長押し待ちが必要 | 「選ぶ」→音符タップで待たず選択。単発で終わり、次の操作は通常に戻る。長押し→詳細の既存入口も残す |
| 数小節をまとめる | 空白長押し→囲む | 時間目盛りを横にドラッグして区間選択。空白の長押し矩形選択も維持。「選ぶ」→空白を囲む方法もある |
| 選ぶだけで作業領域を狭めたくない | 選択で幅282pxのパネルが自動表示 | 入力後・移動後・区間選択では開かない。既存フッター内の固定位置に「聴く・複製・まとめる・詳細」。詳細は明示操作だけ |
| 短い音を扱う | 小さい本体か長押し後の右ハンドル | 直前の入力音、または選んだ短音にだけ移動・伸縮の大きい丸いハンドル。ハンドルのタップでは削除しない。隣接音の本体をハンドルより優先 |
| 鍵盤で和音を弾く | 2本目も画面操作に移行し離鍵が一律 | 鍵盤指を独立した音声と対応。個別離鍵・なぞり・cancel・読込中の離鍵に対応。鍵盤の指はキャンバスの指に数えない |
| 移動途中で画面を動かす | 未確定の変更を破棄 | 画面操作へ即移行し、音符は未確定のまま保留。音符に重ならない上部で適用／取消。再起動・作品ファイルにも保留を保存。後で対象が変わった場合は上書きせず拒否 |
| 今の部分を聴く | 試聴が通常再生と別経路で停止・表示が弱い | 「聴く」1回で選択音の範囲再生。通常のオーディオ時計・停止・再開・表示を使用。再生中の変更も対象IDから反映 |
| 同じ部分を繰り返す | ループ範囲設定後に再生操作 | 選択してループを押せば再生開始。同じ選択範囲で再度押すと解除 |
| フレーズ・別案を残す | 命名ダイアログを毎回経由 | 「まとめる」で元案Aを保持。別案保存は既定名で即保存し、任意の名前変更は別途可能。比較試聴は前の試聴を止めて切り替える |
| 静かに入力する | 入力の試音が常に有効 | 曲の設定に入力音ON/OFFを追加。鍵盤・明示試聴・再生は独立して利用できる |

## 選択と削除の候補比較

同じ音符の同じ短いタップから、削除と選択の両方を無条件に判断することはできない。判断を推測で補うと、ユーザーの指定したタップ削除を変えてしまう。

| 候補 | 確認・比較 | 採否 |
|---|---|---|
| タップを選択へ全面変更 | 削除の1操作を失い、ユーザーの必須条件と矛盾 | 不採用 |
| 長押しだけで選択 | PR #1で実測。範囲複製・繰り返し詳細編集で待ちが積み重なる | 互換の入口として保持。必須にしない |
| ダブルタップなどを増やす | 新しい時間判定が単タップ削除と競合し、習得も必要 | 不採用。人の比較試験を行ったとはしていない |
| 自動選択＋明示的な単発選択＋目盛りの範囲選択 | 同一シナリオの前後試験を実施。音符を置く・直す流れでは選択し直さず、範囲操作から長押しを除去 | 採用。実機の誤操作率・初見理解は未確認 |

「選ぶ」は補助の一回限りの入口で、入力・移動・伸縮の前に押す必要はない。既存音の精密編集を待たずに行う経路は、旧長押し経路より2操作多い。旧経路も残し、このトレードオフを隠して全面的に優れているとは主張しない。

## 近くのメニューと固定操作欄

`/ux/` の比較は、同じ実コマンド欄を密集した音符の上下へ配置し、矩形の遮蔽と移動距離を測る。固定欄は遠くなる代わりに、音符を覆わず位置も変わらない。人の視線移動や好みを測った試験ではない。数値は [12](12_DIRECT_VALIDATION.md)。

採用したのは、既存フッターの固定欄＋任意の詳細パネル。音符選択だけで縦横サイズを変えない。狭い電話幅ではフッターのみ横スクロールし、作曲領域とページ全体を横にはみ出させない。タブレットの検査幅では操作欄全体を表示する。

通常の通知は全体図の場所に表示し、音符を覆わない。

時間目盛りは「タップで再生位置、横ドラッグで範囲」に変更。既存の目盛りドラッグによる連続シークは、この範囲選択へ置き換えた設計上の変更である。シークは目盛りタップ・ミニマップ・数値の再生範囲から行える。

## 内部処理と保護した機能

Canvas2D、音高別インデックス、960 PPQ、stable ID、トランザクション履歴、サンプラー、保存Worker、MIDI形式、音源・ライセンスを維持。フレーズ帯の範囲と音符IDの検索を編集確定時に更新し、画面移動のたびに全音符のMapを作り直さない。

鍵盤の発音は指ID別のMap。読み込みが完了する前に離された音は発音前に中止。単発の入力音は読込待ちで古くなったものを後から大量に鳴らさない。複数鍵盤の和音をこの中止規則に混ぜない。

保留は音符モデルを書き換えずSessionに保存する。適用は1履歴、元の対象が変わった場合は拒否。保留の発生・取消は保存を直ちに要求し、同じ保留中の画面移動は通常の遅延保存でまとめる。

既存の追加・本体タップ削除・ドラッグ・端伸縮・複数音編集・Undo/Redo・複数声部・左右の手・和音転回・ベロシティ・ペダル・テンポ・拍子・フレーズの途中挿入・独立複製・別案・作品管理・MIDI・PWA/オフラインを回帰試験する。録音・AI・自動伴奏・新音色は追加しない。

## 残る条件

実機の指精度、2本指への移行の快適さ、短い音が混むときの操作、長押し、パネルの邪魔さ、初見ユーザーの理解は未確認。合成入力での意図どおりの結果は、人の誤操作率が下がった証拠にはならない。

近接フレーズの帯が重なると先頭の帯を選ぶ。フレーズ一覧からの明示選択を併用できる。画面外自動スクロール・リンク複製等の既存未実装項目は [08](08_IMPLEMENTATION_STATUS.md) のまま。ハードウェア出音遅延と聴感上の連続性も未確認。
