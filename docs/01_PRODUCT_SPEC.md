# 01 — 製品仕様 / Product specification

Status: 設計案 v0.1。ユーザーの要望に基づく仕様。実装・実機での有効性は未確認。

## 1. プロダクトの定義

**TtroPiano** はタブレット優先のピアノ曲作成アプリ。独創性は奇抜なジェスチャーではなく、作曲者が**何をしたいか**を起点に、入力、修正、試聴、反復、構成、演奏表現を1つの編集体験に統合すること。

対象: (A) 楽器を弾かずに画面でメロディーを作る人、(B) ピアノを弾いて曲想を残す人、(C) 音符を精密編集したい人。主要端末: 10–13インチ級タブレット、タッチ／ペン。スマートフォンとPCでも機能を保ち、UIを再配置する。

### JTBD（作曲者が達成したい仕事）

| 意図 | 最短経路の目標 |
|---|---|
| 思いついた音を残す | 空白タップ／鍵盤演奏で即作成 |
| 間違った音を直す | 直接つかんで位置・音高・長さを修正 |
| 今の部分を聴く | その位置から再生／選択部分をループ |
| 2案を比較する | 元案を保管して切替試聴 |
| 伴奏を作る | 声部を追加し、和音／左手の音を編集 |
| 曲として並べる | フレーズとセクションを移動／反復 |
| 表情をつける | 強弱・ペダル・テンポを曲の文脈とともに編集 |
| 途中でやめる／戻る | 自動保存、元に戻す、復元、外部出力 |

## 2. 設計不変条件

P1 **1つの主作業面**: 日常的な音符操作は同じ編集画面から行う。常時のモード切替不要。
P2 **操作の意味を予測可能に**: タップ／ドラッグ／長押し／2本指の衝突規則を明示。ジェスチャーを増やす前に画面上の代替導線を用意。
P3 **操作対象を音楽的に拡張**: 単音→複数音→和音→フレーズ→セクション。ただし「音楽的意味の推定」を勝手に確定しない。
P4 **画面と音はすぐ反応**: 音声・画面・ストレージを別経路にし、保存がUIを止めない設計。
P5 **ユーザー操作は復元可能**: 編集操作は一意の履歴トランザクションでUndo/Redo、失敗の確定や重複を防ぐ。
P6 **段階的開示**: メイン画面の面積はノート編集に割り当て、詳細機能は対象選択時のみ表示。
P7 **見た目より成果**: 初見の迷い・編集時間・誤操作・再生タイミングを測って判断する。
P8 **コアはオフラインで動く**: 作品・素材は端末内に保存可能、ネット接続を作曲の前提にしない。

## 3. MVP機能要求

| ID | 要求 | 完了の判定 |
|---|---|---|
| F-01 | ピアノロールにタッチでノート作成・削除 | ドラッグやパンと衝突せず正しく確定 |
| F-02 | 音高・開始位置・長さの編集 | 拍吸着ON/OFF、精密編集導線あり |
| F-03 | 常時利用できるUndo/Redo | 追加・移動・削除・伸縮が1操作単位で復旧 |
| F-04 | パン／ズーム | 2本指はノート上でも通り、編集処理の完了を待たない |
| F-05 | ピアノ試聴・再生・停止・ループ | ユーザーの再生位置／範囲に従う |
| F-06 | 複数ノート選択・複製・移動 | 範囲選択後も直感的に扱える |
| F-07 | 複数声部（メロディー／伴奏） | 表示／編集対象の切替が容易、声部間移動可 |
| F-08 | テンポ・拍子・グリッド設定 | 途中変更してもノートデータが失われない |
| F-09 | 作品の端末内保存と復元 | 再起動・クラッシュに備える |
| F-10 | MIDIファイル入出力 | ノート／テンポ／ペダル等の対応範囲を明示 |
| F-11 | 初期ピアノ音源の再生 | 端末・ブラウザー動作確認、音源ライセンス確認後搭載 |
| F-12 | タッチ操作とペン操作 | 主要編集導線が両方で機能する |

## 5. 非対象（当面）

- 多楽器DAW化、サードパーティVSTホスト、複雑なミキサー、トラック無制限のレコーディングスタジオ。
- 自動作曲や生成AIを主要な入力手段とすること。
- 音楽理論を推測して音高を無断変更すること。
- 多数の隠しジェスチャー／すべての操作をコンテキストメニューへ押し込むこと。
- フル機能の譜面浄書エンジン、クラウド共同編集（初期版）。
- 機能を減らすためにMIDI出力・正確な保存・演奏表現を犠牲にすること。

## 6. 体験シナリオ（最初に検証する）

S1. 新しい作品を開き、4小節の旋律をタップで入力。数音を移動・伸縮、部分再生して保存。
S2. 既存の2小節を選択し、複製して4小節へ伸ばし、1音だけ変えて比較。
S3. 旋律を鳴らしながら左手の伴奏を追加。声部ごとに編集。
S4. 密集した短いノートを拡大・修正。音符上の2本指でも画面を動かせる。
S5. 誤って消したノートをUndo、続けて編集して保存し、再起動後に復元。
S6. 曲の一部だけリピート試聴し、聴きながら音符を変更。
S7. 作業を中断し、後で作品一覧から同じ場所へ戻る。
S8. 作品をMIDIで出力し、別ソフトに取り込む。

## 7. 「使いやすい」の測り方

実機テストで記録する: 初回4小節完成時間、ノート誤削除、Undo回数、操作モード探索回数、タップから表示更新までの遅延、試聴開始までの時間、画面を探すための視線移動／操作、作成したMIDIの整合性。個々の目標閾値は [06_TEST_PLAN](06_TEST_PLAN.md) に記載し、試験データで調整する。
