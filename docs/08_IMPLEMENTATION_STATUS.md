## 条件と未完了項目

- **Android/iPad/Windows実機の受け入れ、初見ユーザーテストは未確認**。タップ削除と選択方式の比較実験も未実施。タップ削除を指定どおり初期値とする。
- 画面・入力の試験はブラウザーの合成PointerEventを含む。物理タッチの接触精度、OSのジェスチャー、Apple Pencil、Bluetooth音声遅延はその試験から断定しない。
- 音源は元SF3のピアノを抽出した**独自のサンプラー**。元の全SF3ジェネレーター/モジュレーターを再現するエンジンではない。ペダルは離鍵後の減衰を保持する方式。共鳴弦/ハーフペダルの音響モデルは未実装。
- コピーは独立コピー。複製先と元の編集を自動伝播させる「リンク反復」、録音入力、自動運指判定はこの版の未実装拡張。
- キャンバス端の自動スクロールは未実装。2本指移動、ズーム、全体表示、数値編集で表示範囲外を扱える。
- PWAはHTTPSまたはlocalhostが必要。キャッシュが完了する前の初回オフライン起動は不可。OSによるサイトデータ削除への絶対的な保存保証はない。作品ファイルで外部バックアップできる。
- バックグラウンド移行時は再生を一時停止し、位置を保持する。無人バックグラウンド再生を保証しない。
- テンポ/ループ範囲を再生中に変えると現在の拍から再スケジュールする。実機での聴感上のつながりは未確認。
- 検証済み規模と実測値は [10_VALIDATION.md](10_VALIDATION.md)。10万音/16声部はデータの受入上限であり、全端末の性能保証ではない。

## MIDI対応

保持：音高、整数tick、音符長、ベロシティ、声部/トラック名、テンポ変更、拍子変更、CC64ペダル。PPQは960へ変換し最大0.5tick丸める。全音色をピアノにすることは読込時に通知。

未保持：SysEx、CC64以外のCC、ピッチベンド、アフタータッチ、フレーズ/別案、左右の手、ミュート/ソロ、表示位置。形式2/SMPTEは明示エラー。ピアノ以外の音色は再現しない。MIDIに載らない情報は `.ttropiano` 作品ファイルに保持。

MIDI書出しは再生のミュート/ソロと独立し、作品の全音を保存する。全声部共通ペダルは各声部トラックへ複製される。
